- The installer now uses the multi-version layout, matching upstream's structure: programs go into `<base>\<version>.<8 hex>\`, with `maintenance\install-state.json` (the lifecycle state) and `install-manifest.json` and `uninstall.exe` inside the version directory; upgrades no longer overwrite the running version's files
- Fixed: the install information is written to `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\ZhiyuIME` (64-bit view) with `InstallLocation` pointing at the active version directory. It had only been written under HKCU, so the input method could not find the program path when it started the background service on demand — **the service was never started**
- Added the sign-in Run entry `ZhiyuIMEServer` (`zhiyu-server.exe --autostart`), as upstream has; the server exits at once when "Start when I sign in" is off in settings
