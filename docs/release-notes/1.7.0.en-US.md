- New (optional) online AI: a new "AI" page in settings. **Off by default**; once turned on and a feature ticked, only the text that feature works on is sent to the service you configure (about 30 providers built in: DeepSeek, OpenAI, Anthropic, Gemini, Kimi, GLM, Qwen, SiliconFlow, Groq, Ollama, OpenCode Go, …, plus your own address). Keys are stored DPAPI-encrypted; several are kept, and a refused one moves on to the next
- The selection translation (Ctrl+C+C) can run online first: with ai.use_for.translate on it is translated by the API and falls back to the offline model on a timeout or a refusal ("online only" skips the fallback). With it off, or with no network, it behaves exactly as before
- The AI page has the master switch, the service, the address and model (empty uses the service's own; the page shows which is in use), the API keys, the mode, the timeout, the per-feature switches, and a Test button
- A command-line check: `zhiyu-server.exe --ai-test --key <key> [--provider id] [--text "..."]` runs the same path the IME uses
