- 新增（可选）在线 AI：设置里多一页「AI」。**默认关闭**；打开并勾选某个用途后，该功能处理的文字才会发到你填写的服务商（内置约 30 家：DeepSeek、OpenAI、Anthropic、Gemini、Kimi、GLM、通义、硅基流动、Groq、Ollama、OpenCode Go…，也支持自建/代理地址）。密钥用 Windows DPAPI 加密存储，可存多把，一把被拒自动换下一把
- 划词翻译（Ctrl+C+C）可以先走线上：`ai.use_for.translate` 打开后由 API 翻译，超时与被拒会自动回退本地模型（也可设为「仅线上」）；断网、关掉开关时行为与以前完全一致
- 设置页「AI」含：总开关、服务商、接口地址与模型（留空用服务商自带的，界面实时显示"当前使用"）、API 密钥、模式、超时、各用途开关，以及一个「测试」按钮
- 命令行自查：`zhiyu-server.exe --ai-test --key <密钥> [--provider id] [--text 文本]` 走与输入法相同的链路
