- 新增（可选）在线 AI：设置里多一页「AI」，**默认关闭**，关着时与以前完全一致
- 划词翻译（Ctrl+C+C）可以改走线上 API：打开总开关并勾选“划词翻译”后由 API 翻译；超时或被拒会**自动回退本地模型**（也可设成“仅线上”）。内置约 30 家服务商（DeepSeek、OpenAI、Anthropic、Gemini、Kimi、GLM、通义、硅基流动、Groq、Ollama、OpenCode Go…），也能填自建/代理地址
- API 密钥用 Windows **DPAPI 加密**存储；可按服务商分别保存**多把**，一把被拒自动换下一把；“显示/隐藏”可查看输入内容，“识别”可按地址认出服务商，“获取模型”可拉取该家模型列表
- 思考模式与推理等级**按服务商与模型自动适配**：各家的“关闭思考”字段自动映射（如 DeepSeek/智谱用 `thinking`、通义用 `enable_thinking`），推理等级列表按当前服务商+模型给出，不支持思考的服务会置灰。关掉思考可明显提速（实测同一句：4210 ms → 约 1900 ms）
- 「测试」按钮显示**耗时(ms)**与结果
