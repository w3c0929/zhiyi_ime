- **AI actions on the selected text work now**: select some text, press the translate key (Ctrl+C by default; the program copies the selection first), then the action menu key, and a menu opens at the caret (**Polish / Proofread / Rewrite**). Pick with a number or the arrow keys and press Enter: the answer **replaces the selection** (one Ctrl+Z undoes it). While setting the menu key on the AI page, hold Ctrl, press C, then press the key you want (the second key is what is stored)
- Each action can also have **a key of its own** (the box at the right of its row): pressing it runs that action straight away, with no menu; the checkbox at the left decides whether the menu lists it
- **Fixed: choosing an action returned nothing.** The answer only comes back through the long-text channel, while the short-text branch read another field, found nothing and stopped
- **Fixed: the action menu key opened nothing.** The trigger was written but never called from the key handling
- **Fixed: Backspace did not clear the key box while it was taking a key.** Backspace, Delete or a right click clears it now
- Fixed: a selection longer than 1000 characters was silently cut to 1000, and with "type the translation over the selection" on, the whole selection was replaced by the translation of that short piece (the rest was lost). The limit is now `translate.max_selection_chars` (32000 by default); a longer one is reported with "only the first N characters were used" and is **shown, never typed back**
