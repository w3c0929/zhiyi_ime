- **选中文字的 AI 动作可以用了**：选中一段文字 → 先按划词翻译键（默认 `Ctrl+C`，程序会先复制这段文字）→ 紧接着按「动作菜单键」→ 光标处弹出菜单（**润色 / 纠错 / 改写**）→ 按数字键或方向键选、回车执行，结果**替换选中文字**（`Ctrl+Z` 一步撤销）。设「AI」页的「动作菜单键」时，直接按住 Ctrl 按 C 再按想要的键即可（记的是第二个键）
- 每个动作还能配**自己的键**（设置页每一行右边的框）：按它就直跑那个动作、不弹菜单；左边的勾选框决定它是否出现在菜单里
- **修：AI 动作选完没有结果**。答案只能通过长文本通道取回，而短文本分支去读了另一个字段，于是拿到空值就结束了
- **修：动作菜单键唤不出菜单**。触发判定写了却没接到键盘处理上
- **修：捕获框在「正在按键」状态下按 Backspace 不能清空**。现在按 `Backspace` / `Delete`（或右键）都能清空
- 修：划词翻译选区超过 1000 字时会被静默砍成 1000 字，若开着「直接上屏」还会把整段选区替换成那一小段的译文（后面的原文就没了）。现在上限是 `translate.max_selection_chars`（默认 32000 字），超长会提示「只处理了前 N 字」且**只显示、不替换**
