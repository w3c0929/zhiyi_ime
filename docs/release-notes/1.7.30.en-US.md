- **AI actions are one key press now**: with text selected, **press the action menu key** and the menu opens (pressing an action's own key runs it straight away). The selection is read for you - in programs TSF cannot read it presses `Ctrl+C` itself and takes the clipboard - so there is **no Ctrl+C of your own** to press first
- The key may be any of: **a key like `F6`**, a combination like `Ctrl+K`, or a **tapped** right Shift / Shift / Ctrl. A tap is decided on the key-up, so an ordinary `Shift+A` is never mistaken for one
- Fixed: an action key set in 1.7.28 stopped working in 1.7.29 (the key moved from `shortcuts.ai_action` to `ai.action_key` and the old value was not read back). It is read back now, so nothing has to be set again
- The key box in Settings takes a **tapped modifier** (shown as "Right Shift" and the like), and `Backspace` / `Delete` or a right click clears it
