- **Translate is an AI action now**: the menu gained "Translate", with a key of its own like polish/proofread/rewrite (one press runs it). It goes through the **selection translation's service** (online first, falling back to the offline model), so it uses the same model Ctrl+C+C does; **Ctrl+C+C itself is unchanged**
- **The translate action's language and direction**: the Translate row's drop-down offers **12** languages (English, Chinese, Japanese, Korean, French, German, Spanish, Russian, Vietnamese, Portuguese, Italian, Arabic; `ai.translate_language`, English by default). **Chinese** goes into the one selected; **anything else becomes Chinese**; the **offline model always follows the Learning page's two candidate rows**, exactly as Ctrl+C+C does. The offline model covers nine of them; Portuguese, Italian and Arabic are online only
- **New "Summarize" action**: a short paragraph in the same language, **previewed, never typed back** (32000 characters, 60 s), for longer passages
- The Learning page's candidate translations are back to **two rows** (Chinese, English candidates): those are the candidates an input method has, and the other languages are the Translate action's drop-down now. Japanese and the like still follow the English row's target, so nothing changes for the translate key
- The actions stay data (`data/ai_actions.json`): another action, another prompt or another limit needs no new code
