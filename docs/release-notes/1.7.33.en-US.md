- **Fix: `\fy` never opened the language list.** The menu command was turned away by an internal allow-list (`UiCommandType::kAiLanguageMenu` was not registered), so the server never sent it and nothing happened on screen. Typing `\fy` now opens the 12 languages at the caret
- **Summarize now writes *under* the selection** instead of only previewing: the summary goes in as a paragraph of its own after the selected text (the text itself is left alone; `Ctrl+Z` undoes it in one step). A summary is read while looking at the passage, so it belongs underneath it
- That is a third destination (`insert` in `data/ai_actions.json` is now `replace` / `below` / `preview`); set an action's `insert` to `below` to have its answer written under the selection too
- A selection longer than the action's limit (or than `translate.max_selection_chars`, 32000 characters by default) is still handled: a "below" action writes its answer as usual and adds "（only the first N characters were used）" as the last line, while a "replace" action falls back to showing the answer only, so the part that was not processed is never lost
