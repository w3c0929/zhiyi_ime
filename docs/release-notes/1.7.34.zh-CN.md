- **修：`\fy` 打不出来语言列表**。菜单命令连续被两道「新命令要登记」的关口挡掉了：服务端 `valid_command_type()` 的白名单没写 `UiCommandType::kAiLanguageMenu`（包压根没发出去），收端 `decode_ui_command_packet()` 又拿 `> kRefreshCandidates` 当上限把它当成「更新的服务端发来的、不认识」而丢掉。现在两处都补上，并加了一个 `kLastKnown` 上限常量，以后加命令只改这一处就行。按下 `\fy` 会在光标处弹出 12 种语言（竖排列表）
- **修：`\fy` 弹出来的列表会被自己关掉**。清掉 `\fy` 这段组字算一次编辑，而「有编辑就关动作菜单」的逻辑会顺手把刚弹出的列表关掉；语言列表不依赖选区，现在豁免
- **摘要改成写在选中文字的「下方」**：不再只是弹个预览窗，而是把概括结果作为独立的一段**插到选区后面**（原文一个字都不动，`Ctrl+Z` 一步撤销）。摘要是给别人看这段文字时用的，放在原文下面才读得顺
- 这是新的第三种去向（`data/ai_actions.json` 里 `insert` 现在有 `replace` / `below` / `preview` 三种），以后想让某个动作写在下方的，把它的 `insert` 改成 `below` 就行
- 选区太长（超过动作上限或 `translate.max_selection_chars`，默认 32000 字）时，写在下方的动作照常插进去，并把「（只处理了前 N 字）」作为最后一行一起写上；要**替换**选区的动作仍改成只显示，免得丢掉没处理的部分
