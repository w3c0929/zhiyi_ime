- **You choose which action the voice post-processing runs**: the new setting `ai.voice_polish_action` (the `ai` section of `%USERPROFILE%\zhiyu\default.json`) takes the id of an action in `data/ai_actions.json` — **`proofread` by default**; set it to `polish` to have what you dictate polished instead, and **leave it empty to skip this step** (the recognized words are typed as heard, the purpose switch stays on). It is a configuration file change, no restart needed
- The prompt and the length limit are the action's own (the same ones "selection → that action" uses), so the two agree; an id the data file does not have, or an action without a prompt, falls back to the recognized words
- The timeout is still `ai.timeout_ms` (8 s), not the action's own `timeout_ms` — Proofread's is 20 s, longer than 8, and waiting it out would be worse
