- **语音识别后处理用哪个动作可以自己定**：新增配置 `ai.voice_polish_action`（`%USERPROFILE%\zhiyu\default.json` 的 `ai` 段），值是 `data/ai_actions.json` 里某个动作的 id，**默认 `proofread`（纠错）**；想让语音过去「润色」就改成 `polish`，**留空则这一层不做**（识别文字原样上屏，用途开关保留）。改配置文件即可，不需要重启输入法
- 提示词与字数上限跟着那个动作走（就是「选中文字 → 同一动作」用的那一份），所以两边规矩一致；动作 id 写错或该动作没有提示词时，退回识别原文
- 超时仍是 `ai.timeout_ms`（默认 8 秒），没有改用动作自己的 `timeout_ms`——纠错那个是 20 秒，比 8 秒还长，等满更难受
