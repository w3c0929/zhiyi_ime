- **Fix: an action's character limit was counted in bytes, about three times stricter for Chinese.** The client cut the selection by characters (8000 meant 8000 of them) while the server judged the same number in UTF-8 bytes — so a 3000-character Chinese selection was refused as "over the limit" and the action simply failed. Both sides count **characters** now (`ai_text_length`), and the voice post-processing was making the same mistake
- **Fix: a window no longer sticks at "translating…".** When the service had nothing for us at all (the request never arrived, or it gave up on it) the client stopped polling and left the "正在翻译…／正在润色…" window on screen for ever; it now finishes the job and says "无法完成：服务没有返回结果"
- **Fix: a key never does nothing in silence any more.** With nothing selected and no text on the clipboard, and when sending fails (the connection to the server is gone), the caret shows why — the selection translation used to be silent in both cases, which made the key look broken
- Docs: an action's `timeout_ms` in `data/ai_actions.json` has no effect today (requests use `ai.timeout_ms`); `docs/ai.md` now says so
