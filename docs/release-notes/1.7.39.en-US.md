- **A key now copies first and handles what it copied**: the selection when there is one, and with nothing selected **the line the caret is on** — which is selected for you (you see it happen) — then a `Ctrl+C` is sent for you and the **copied text** is what gets processed. What is handled is, from now on, always something you can see
- **The clipboard's leftover content is never used**: the old "nothing selected, so take whatever is on the clipboard" made the same key work on text you could not see — the root of the confusion. The clipboard now only ever holds what this key press copied, which also removes the risk of a leftover password being sent off for processing
- **The answer lands where a selection's would**: a replacing action replaces that line (it is no longer inserted mid-sentence), and a summary is written as its own paragraph **under the line**
- In a single-line box (a chat box, a search box) "the line" is the whole box
- When there is nothing to take (no selection and an empty line, or a program that will not let the input method read its text) the reason is shown; a key never does nothing in silence
