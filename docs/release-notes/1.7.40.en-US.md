- **Fix: the action menu key stopped working** (1.7.39's doing). 1.7.39 made the key copy first, and that copy was a `Ctrl+C` sent *to the program* — whose injected `C` the input method's own key handling then saw, so **the menu that had just opened was closed by it** (only programs that cannot be read used that copy before, which is why it had not shown up). Now a readable program is never sent key events: the text goes on the clipboard directly (the copy the user asked for, without any key of ours), and only a program that cannot be read is asked to copy — those keys carry a mark the input method skips
- **"The current line" is now what you asked for: from the line's start to the caret**, not the whole line, and it is selected so you can see it. A replacing action replaces that part — **text to the right of the caret is left alone** — and a summary lands after it
- In a single-line box (a chat box, a search box) it is what is **before the caret**, not the whole box
