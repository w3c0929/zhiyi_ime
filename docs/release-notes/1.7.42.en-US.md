- **Undo is the program's own `Ctrl+Z`; the input method keeps out of it.** It never did intercept `Ctrl+Z` (any Ctrl/Alt combination is passed straight through to the program) and it has no undo stack of its own, so there is one undo, the program's, and no second one to fight with
- **One change**: the text an action writes is no longer marked "a correction of what it replaces" (`TF_ST_CORRECTION`). That mark is for a **composition's commit** — turning pinyin into characters really is a correction — while an answer is not a correction of anything, and some programs fold a correction into the edit before it, which is how an undo stops being one step. It is an **ordinary edit** now: the program records it the way it records typing, and `Ctrl+Z` takes it back in one step
- A summary written under the line is one ordinary edit too (including its "only the first N characters" note), taken back together
- Committing a composition (picking a candidate) and the voice text go the way they always did — untouched
- **Settings, AI actions card: the column beside the action rows showed a string key** (`ai.action_list` was missing from both string files, so the key itself was drawn) — it reads "Actions" now
- **An action's name and the key box beside it were far apart**: the checkbox is now as wide as the **longest action name actually measures**, with the key box right after it, and the translate row's language drop-down follows (the row is compact in both the Chinese and the English interface)
