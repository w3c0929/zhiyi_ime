- **动作键/菜单键的"要处理的内容"现在是三级来源**（按顺序找，找到就用）：① 有选区 → 用选区；② 没选中 → 用**光标这一行从头到光标**那一段（会替你选中并放进剪贴板）；③ 前两级都没有 → 用**剪贴板里的内容**，也就是**你之前 `Ctrl+C` 复制的东西**
- 这样"复制一段 → 到空输入框（或到不给文字的程序里）按键"就能直接处理那一段，不用先粘贴出来
- **剪贴板排在最后**：它永远不会盖掉你光标处的选区或那一行，所以不会出现"我要处理这一行，它却处理了别的东西"；走到第 3 级时，处理的文字就显示在窗口里（"正在润色…"下面那行），一眼能看出用的是哪一份
- 取不到内容时的提示改成：「没有可处理的内容（没选中、光标这一行没字、剪贴板里也没有文本）」——把三级都点明，省得猜
- **密码框一律不动**：既不读它，也不拿剪贴板顶替
