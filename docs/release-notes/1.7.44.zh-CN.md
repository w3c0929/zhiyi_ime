- **修：在 Sublime Text 这类"老式编辑器"里，动作能跑、结果能上屏，但输入法自己的小窗口（正在润色…／动作菜单）看不见**。原因：读文字时输入法会替你复制一次，而这类程序（尤其**以管理员身份运行**时）会因此**重新激活它的输入上下文**，输入法随即收到"输入目标变了"——那条清理逻辑会**立刻把刚弹出的窗口收掉**，所以看起来像没弹过。浏览器里不会这样，所以在 Chrome 里一直正常
- **改法**：给这批窗口一个 **0.9 秒的宽限期**——刚弹出的这片刻里，"输入目标变化"不再收掉它们；同时留下一条诊断痕迹（`ai_ui`），万一还有别的程序有同样毛病，日志能直接指出是谁收的
- 顺带说明：这类程序里"光标所在那一行"取不到（它们把文字藏起来，TSF 读不到），所以走的是**剪贴板**那一路——按动作键前先 `Ctrl+C` 一下即可；选区仍然照常可用
