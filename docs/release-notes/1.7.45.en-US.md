- **Fix: with the menu key set to a *tapped* modifier (right Shift, say) the menu would not open in Sublime Text and programs like it.** Such a program never hands a text service the modifier's key-up, and a tap was decided by exactly that event — so the decision never came. It is decided by the key's own state now (checked on a timer): released, with no other key in between, is a tap
- **Fix: in such a program an action's answer was inserted at the caret instead of replacing what you had selected.** The program keeps its text to itself, so TSF sees no selection to replace. The answer goes in the way you would put it there — on the clipboard, then Ctrl+V — and the program replaces what it has selected; `Ctrl+Z` still takes it back in one step, with the program's own undo
- An action that writes *under* a selection (a summary) is **shown only** in such a program: pasting would throw the selection away
- This build also carries **1.7.44** (the grace window that stops an editor's input-context bounce from taking the action's window away), so update once and test both
