- **New: the language list can have a key of its own.** The AI page has a "**Language list key**" row (below the action menu key; `ai.language_key`): one press opens the **list of 12 languages** — the one `\fy` opens — and picking one sets the language on the Translate row. It is written exactly like the action menu key (a key like `F6`, a combination like `Ctrl+K`, or a **tapped** right Shift); empty: off
- It goes the same way `\fy` does: the input method simply types those three keys for you, so the candidate bar, the number and arrow keys, the paging, the mouse click, and the "write it into the settings" step are all the ones the command already has. It does not fire while a composition is going — there `\fy` would only be punctuation
- The key needs nothing selected: it works in any input box
