- **新增：语言列表也能配一个键**。设置「AI」页「动作菜单键」下面多一行「**语言列表键**」（`ai.language_key`）：按一下就直接弹出 **12 种语言的列表**——就是打 `\fy` 弹出的那张表，选中即存进「翻译」那一行的语言。写法与动作菜单键**完全一样**（`F6` 这类单键、`Ctrl+K` 这类组合、或**轻按**右 Shift）；留空 = 关闭
- 它和打 `\fy` 走的是同一条路：输入法只是替你按下那三个键，所以**候选条、数字键/方向键/翻页、鼠标点选、以及"选中后写入配置"全都一致**；正在打拼音（组字中）时不触发——那时 `\fy` 只会是标点
- 这个键**不需要选中内容**，任何输入框里都能用
