- **Fix: the language list key could not be set** (it went empty the moment you pressed OK or Apply). The settings page keeps a list of "edits made on a page that must survive a reload", and the new key was not added to it — so the panel's reread dropped the edit before it could be saved. It is on that list now (`KEEP_PAGE_EDIT(ai.language_key)` in `editor_app.cc`)
- **Fix: in Sublime Text and the like the answer was still inserted instead of replacing.** The previous build judged "this program keeps its text" by "is this a transitory document", which is not why *that* program refuses to be read, so the paste path was never taken. It now goes by **what the read actually saw**: whenever this read could not read the document at all (the text came from the program's own `Ctrl+C`, or from the clipboard), the answer is delivered by **pasting** — the program replaces what it has selected
- **Better diagnostics** (for this hunt only): the answer window and the menu now record their owner, position, **whether they came up visible**, their rect, and which way the answer went (paste or insert) — so the next log says outright whether the window was created, where it went, and whether it was seen
