- **Fix: in Sublime Text and the like, with nothing selected the answer landed in the middle of the line and left it duplicated.** Measured: with no selection such a program's Ctrl+C copies the **whole line** (26 characters + its break = 28), while our answer was **pasted at the caret** — so the line came out doubled. Now, when the copy is put down to be **exactly one line**, its trailing break is taken off (that is what gets worked on) and the program is asked to **select that line** (`Home`, `Shift+End`) before the paste — so the answer **replaces the line**. Only for a single line: with several, the line we could select is not the text that was worked on, so nothing is touched
