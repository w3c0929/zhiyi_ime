- **修：答案一步就能撤销**。之前把答案写回选区用的是 TSF 直接写入，**有些程序根本不把它记进撤销栈**——实测 Win11 Notepad：按一次 `Ctrl+Z` 会把**整个文档清空**（它去撤销了上一步"把原文粘进去"的那次粘贴），再按多少次都回不来；用输入法**自己打字**覆盖同一个选区也一样回不来，这是 Notepad 对"输入法写入"的撤销整合本身的毛病 ✗
- 现在替换选中的答案**改用粘贴送回**（答案放进剪贴板 + 一次 `Ctrl+V`，由程序用自己的选区完成替换）——这正是各家都能一步撤销的写法：Sublime Text 本来就这么送，Chrome 上实测（1.7.56）**一次 `Ctrl+Z` 原文完好回来**；Notepad 里对同一份文档手工粘贴覆盖后，一次 `Ctrl+Z` 同样能还原（它的 TSF 写入路径则不能）✓
