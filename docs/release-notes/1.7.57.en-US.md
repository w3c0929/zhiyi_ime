- **The backslash commands work in English too**: `\` is a command prefix while typing English (the ASCII mode a tap of Shift switches to), not only while typing Chinese — `\fy` opens the translation-language list and `\bd` lists the punctuation candidates there as well
- **`\\` types one literal backslash** in English mode (in Chinese mode `\\` still types `、`, unchanged)
- **What no command can continue is text**: with a `\` that begins nothing (a path like `C:\Users`), the keys are typed as they came, capitals and all, and no candidate window is left hanging; a `\b`-style code with candidates still uses the digits, Space and the arrows to pick one
- **A tapped modifier means one thing**: once a modifier is made an AI key (`ai.action_key`, an action's own key, or `ai.language_key`), pressing it does that and nothing else — the right Shift used to be both the action menu key and a switch for Chinese/English, which in a browser showed up as "the right Shift switches the input mode and the menu never opens"; the engine now takes that modifier out of the tap-to-switch table. Measured: a right Shift tap opens the menu and leaves the mode alone, a left Shift tap still switches it
- **The line is selected differently**: in a program that keeps its text and copies the whole line when nothing is selected (Sublime Text and the like), the answer has to replace the caret's line — it is now selected with **`Home` + `Shift+End`** and an automatic **`Ctrl+C`** (no longer `Ctrl+L`), and the answer is pasted over it. A program whose selection TSF itself can set (more exact) is tried first, and which way worked is remembered per program
