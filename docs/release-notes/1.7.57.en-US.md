- **The backslash commands work in English too**: `\` is a command prefix while typing English (the ASCII mode a tap of Shift switches to), not only while typing Chinese — `\fy` opens the translation-language list and `\bd` lists the punctuation candidates there as well
- **`\\` types one literal backslash** in English mode (in Chinese mode `\\` still types `、`, unchanged)
- **What no command can continue is text**: with a `\` that begins nothing (a path like `C:\Users`), the keys are typed as they came, capitals and all, and no candidate window is left hanging; a `\b`-style code with candidates still uses the digits, Space and the arrows to pick one
