- **The action menu key only opens the menu — it no longer copies for you**: pressing the action menu key (unset by default; a single key like `F6`, or a tapped modifier) only shows the menu; the text is read when you pick a row (1 Translate / 2 Polish / 3 Proofread / 4 Rewrite / 5 Summarize), so one press no longer puts your selection on the clipboard. Digits, the arrows (`↑`/`←` back, `↓`/`→` on, `Tab` forward too), `Space` or `Return` to run one, `Esc` to cancel, or click a row
- **The Chinese/English switch can split its two sides**: the arrow in that row's box now offers nine ways — either side switches Chinese/English, left only, right only, left English with right Chinese (or the other way round), left English only, left Chinese only, right English only, right Chinese only. The box says which one is set (e.g. `Shift · 左英文，右中文`). A *side* is what counts as taken: with the switch on left Shift, right Shift is still free for another switch key
- **New "Default input language"** (the top row of Settings > Keys): Chinese / English / **Automatic** — what a window or program opened from now on starts in (a window already in use keeps its own). *Automatic* remembers the language each program was left in and starts it that way next time; the record stays on this computer in `%USERPROFILE%\zhiyu\program-languages.json` (program file names and languages only, never uploaded) and is neither read nor written while Chinese or English is selected
