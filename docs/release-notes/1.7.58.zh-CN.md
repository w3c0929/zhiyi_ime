- **动作菜单键只弹菜单，不再替你复制**：按下动作菜单键（默认没设，可设成 `F6` 这类单键或轻按某个修饰键）只把菜单弹出来；**选了哪一项（1 翻译 / 2 润色 / 3 纠错 / 4 改写 / 5 摘要）才去读你的文字**，所以按一下菜单键不会把选中的内容放进剪贴板。数字键、方向键（`↑`/`←` 上一项，`↓`/`→` 下一项，`Tab` 也向后）、`空格`或`回车`执行、`Esc` 取消，鼠标点那一行也行
- **中英切换可以左右分工**：「按键」页中英切换那一行，框右侧的箭头现在给出九种玩法——左右都可中英切换、左仅中英切换、右仅中英切换、左英文右中文（或反过来）、左仅英文、左仅中文、右仅英文、右仅中文；框里会写清当前是哪一种（如 `Shift · 左英文，右中文`）。占用按**侧**算：中英切换用了左 Shift，右 Shift 还能给别的切换键
- **新增「默认输入法」**（「按键」页最上面一行）：中文 / 英文 / **自动**，管的是新打开的程序从哪种输入状态开始（已经开着的窗口保留它自己的）。**自动** = 记住每个程序上次用的那种、下次打开照旧；记录只在本机 `%USERPROFILE%\zhiyu\program-languages.json`（只有程序文件名和语言，不上传），选中文或英文时这份文件既不读也不写
