- **The recommendation model becomes Zhiyu 1.4V2-Long-L18** (the same file as the upstream Zhiyi IME 1.5.9 default model): 1.4V2 with 18 of its 22 encoder layers (the four sliding-window layers removed); its word choice was distilled from a fine-tuned Qwen3.5-9B teacher on about 1.7M rows of the IME's real candidates. The choice input is now the context first, each candidate written once, no instructions — about 40% fewer tokens per page. First candidate right on the new test set: Chinese words and pairs 84.4% → **86.2%**, long input 66.5% → 67.2%, English words 87.7% → **90.2%**, Chinese typed as initials 71.9% → **77.7%**, English first letters only 71.7% → **77.3%**; about 26 ms → **14.6 ms** per page on the CPU. Long pinyin is still composed by the model after the pause
- **The installer is about 8 MB smaller**: the new model is one 96 MB graph instead of the old 84 MB model plus a 34 MB decoder (and its two KV cache graphs). The old decoder model still loads, and `laya.decoder_beam` / `laya.decoder_cache` apply to it only
