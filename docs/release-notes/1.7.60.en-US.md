- **New: a download mirror** (Settings > General). With it ticked, the update check, the installer, and the language pack, translation model and voice model downloads all go through the GitHub mirror you pick — 24 built-in ones, and Custom lets you type an `https://` mirror prefix. A mirror only proxies: the files are still verified against the release's **signature and SHA-256**, so it cannot pass off other content, and no keys, settings or typed text pass through it. Unticked goes to GitHub directly
- **Fixed: settings could not be saved after an update** ("后台服务没有采用这份配置…The data is invalid. (13)"). An update retires the old version directory — its `data\default.json` included — while the server started from that directory keeps running; unable to read its package settings it rejected every save. The server now switches to the package settings of the installed version by itself when its own are gone (it says so in `problems.log`), so no manual restart is needed
