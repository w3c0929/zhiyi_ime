- **Fixed: in English mode a letter was "typed" by the IME, which ate every single-key shortcut.** The IME used to commit an A-Z key as a character of its own (an old design; in a text box it looks exactly like the host typing it, so it went unnoticed) — but a program whose shortcut is a single letter receives "an inserted character" instead of "a key press", so the shortcut never fires: REAPER's `D` opened nothing, and single-letter commands in DAWs and games were dead the same way. A half-width letter is now left to the host (which types the same letter), exactly like Space and Enter in the same block already were. Full-shape mode still writes the full-width letter itself. Microsoft Pinyin has always passed letters through in its English mode, which is why it never had this problem
- **New: "Programs the keyboard is left to"** (Settings > General). Type program file names (`reaper.exe`, separated by commas or spaces) and in those programs the input method takes **no keys at all** — nothing is composed, no candidate window opens, no key is intercepted. Meant for programs where the keyboard should be handed over **even in Chinese mode**; the English-mode single-letter problem above is fixed at the root, so most programs do not need this. The cost: you cannot type Chinese in the programs listed
