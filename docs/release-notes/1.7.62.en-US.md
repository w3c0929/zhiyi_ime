- **Voice post-processing can now "ask"**: recognised speech used to go through "纠错" (proofread) only; the row in Settings > AI is now a drop-down with **three items — 纠错 / 提问 / 不使用** (proofread / ask / not used). "纠错" fixes typos; "提问" sends **the recognised sentence to the AI as a question and types the AI's answer**, not the recognised words. Picking either action turns the feature on; "不使用" turns it off. The drop-down is the switch itself — the old tick beside it is gone
- **New "voice action key"** (`ai.voice_action_key`, the row under "语言列表键" in Settings > AI): set a key (e.g. `F12`) and pressing it in a text box pops up a **three-row list, "纠错 / 提问 / 不使用"** — the same three choices in the same order as the drop-down. Digits, arrow keys, Space or Enter to run, Esc to cancel, or click with the mouse. **Picking a row writes it into the settings**, so there is no trip to the settings window. If any step fails (master switch off, no API key, timeout, over the length limit) the **recognised text is typed instead** — what you dictated is never lost
- **New AI action "Ask"** (selected text → row 6 of the action menu, or give it its own key): the selected sentence **is the question**, and the AI's answer is written **below the selection** (the original stays); the answer is in the language of the question
- **Removed the "fallback translation when the glossary misses" tick**: it was never implemented — what actually handles a glossary miss is the **offline translation** on the Learning page (the local translation model), which has always been there
