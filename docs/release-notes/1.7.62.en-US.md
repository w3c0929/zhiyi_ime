- **Voice post-processing can now "ask"**: recognised speech used to go through "纠错" (proofread) only; the row in Settings > AI now has **two radio buttons** — "纠错" (proofread, the default: fix typos) and "提问" (**ask: the recognised sentence is sent to the AI as a question, and the AI's answer is what gets typed**, not the recognised words). Picking either one **ticks "语音识别后处理" for you**, since a choice that is not enabled does nothing
- **New "voice action key"** (`ai.voice_action_key`, the row under "语言列表键" in Settings > AI): set a key (e.g. `F12`) and pressing it in a text box pops up a **two-row list, "纠错 / 提问"** — digits, arrow keys, Space or Enter to run, Esc to cancel, or click with the mouse. **Picking a row writes it into the settings** and turns the purpose switch on, so there is no trip to the settings window. If any step fails (master switch off, no API key, timeout, over the length limit) the **recognised text is typed instead** — what you dictated is never lost
- **New AI action "Ask"** (selected text → row 6 of the action menu, or give it its own key): the selected sentence **is the question**, and the AI's answer is written **below the selection** (the original stays); the answer is in the language of the question
- **Removed the "fallback translation when the glossary misses" tick**: it was never implemented — what actually handles a glossary miss is the **offline translation** on the Learning page (the local translation model), which has always been there
