- **Fixed: 「摘要」/「提问」only showed their answer in a program the input method cannot write into** (Sublime Text and the like) instead of writing it below the selection. Those programs keep their text to themselves — TSF sees a transitory document, so neither the selection nor the text can be read — and an "under the selection" action had nothing to write with there, so it fell back to showing the answer in the window. It now uses **the program's own keys**: the caret is taken to the end of the selection (`Right`; `End` when the program is one that copies the caret's line because nothing was selected) and **"newline + answer" is pasted** there — the original text does not move at all, the answer lands on the line below it, and one `Ctrl+Z` takes it back
