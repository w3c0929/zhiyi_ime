- **The "prefer online / online only" modes are gone: one switch is left.** The "online AI" tick (`ai.enabled`) is now the whole of it — on means the API comes first and **every failure falls back** (selection translation to the offline model, voice to the recognised words); off means nothing goes online at all. The mode drop-down is gone, and so is the `ai.mode` field (a value left in an old file is ignored)
- **An "online AI key" now sits beside that tick** (`ai.enable_key`, Settings > AI): set a key (e.g. `F11`) and pressing it in a text box pops up a **two-row list, "线上（开）" / "线上（关）"** (online on / online off) — digits, arrow keys, Space or Enter to run, Esc to cancel, or click with the mouse. Picking a row writes the same setting the tick does, so there is no trip to the settings window
- **The selection translation key (Ctrl+C+C) now translates into the AI page's "translate language" while online**: Chinese goes into the language picked there, anything else goes into Chinese. **The offline model (the fallback) still follows the Learning page's two rows**, exactly as before
