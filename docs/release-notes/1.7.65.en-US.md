- **New: a web search, used by 「提问」 (Ask) only.** Under the online switch on the AI page there is now a **Search** row (the "Search the web" tick and, beside it, a search key) and under that a **Service** row: a **Tavily / DeepSeek** drop-down, that service's key box, and a "Get an API key" link beside the box (link and explanation follow the service). With it on, **an Ask searches that sentence first and hands the results to the AI along with the question** — the answer ends with the sources it used. Polish / proofread / rewrite / summarize / translate never search; with no key, the switch off, nothing found or a failed request, it answers exactly as before instead of failing
- **Voice uses the same search**: with voice post-processing set to 「提问」, the recognised sentence goes through **these same settings** (the same switch, service and key) — searched first, then answered
- **Two services**: **Tavily** (sign up and the key is right there; the free plan includes 1000 credits) and **DeepSeek's own search API** — its box can be **left empty to use the DeepSeek key from the AI section** (the same platform key), or given a key of its own. Both keys are DPAPI-protected like the API keys, never stored in clear
- **The search has a switch and a key of its own**: pressing the **search key** (`ai.search_key`) in a text box opens a **four-row list — 搜索（开）/ 搜索（关）/ Tavily / DeepSeek** (the service in use is marked "（当前）", current) — digits, arrow keys, Space or Enter to run, Esc to cancel, or click with the mouse. Picking a row writes the settings, so there is no trip to the settings window
