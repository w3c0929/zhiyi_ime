- **新增联网搜索，只有「提问」会用**：「AI」页「在线 AI」下面多了一行**「搜索」**（勾选框「启用联网搜索」+ 右边的「搜索开关键」），再下面一行是**「来源」**：下拉 **Tavily / DeepSeek** + 该来源的密钥框 + 框右边的「获取 API Key」链接（链接与说明跟着来源换）。打开后**提问时先把那句话拿去搜一页结果，再把结果连同问题一起交给 AI**，回答末尾列出用到的来源。**润色 / 纠错 / 改写 / 摘要 / 翻译都不搜**；没填密钥、开关关着、搜不到或请求失败，都照旧直接回答，不会因此失败
- **语音那边选「提问」也一样搜**：语音识别后处理选「提问」时，识别出来的那句话**用的就是这套搜索设置**（同一个开关、同一个来源、同一把密钥）——先搜一页结果再交给 AI
- **两家搜索**：**Tavily**（注册就能复制 key，免费额度 1000 credits）与 **DeepSeek 自己的搜索接口**——DeepSeek 那一栏**留空就用「AI」里那把 DeepSeek 密钥**（同一个平台的 key），也可以单独填一把覆盖它。密钥与 API 密钥一样 DPAPI 加密保存，不写明文
- **搜索也有自己的开关和快捷键**：「搜索开关键」（`ai.search_key`）在输入框里按一下就弹出**四行「搜索（开）/ 搜索（关）/ Tavily / DeepSeek」**（当前在用的那家标着「（当前）」）——数字键、方向键、空格或回车执行，Esc 取消，也可以鼠标点；选中即写进配置，不用进设置页
