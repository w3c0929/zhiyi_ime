- **Fixed: the input method was unusable in the Windows 11 search box (Win+S)**. That box is an AppContainer process (`SearchHost.exe`, low integrity), and an AppContainer only loads DLLs it can read. `C:\Program Files` and `System32` carry the "ALL APPLICATION PACKAGES: read & execute" entry by default; an install anywhere else (a scoop persist folder, for instance) has no such entry, so the IME's DLL was never loaded and the box looked like "the IME is disabled". The installer now grants **ALL APPLICATION PACKAGES** and **ALL RESTRICTED APPLICATION PACKAGES** read & execute on the version directory (by SID, so it is the same in any Windows language). **No code signing is needed for this** — and none of the free signing options would have helped.
