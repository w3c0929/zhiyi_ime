- **修：Win11 的搜索框（Win+S）里输入法整个用不了**。那个搜索框是 **AppContainer 进程**（`SearchHost.exe`，低完整性），它只能加载**自己读得到**的 DLL：`C:\Program Files`、`System32` 天生就有"所有应用程序包：读取和执行"这条权限，装在别处（比如 scoop 的 persist 目录）就没有——DLL 根本不加载，看起来就像"输入法被禁用 / 需要签名"。现在**安装器会给版本目录授「ALL APPLICATION PACKAGES」与「ALL RESTRICTED APPLICATION PACKAGES」的读取和执行权限**（按 SID 授，任何语言的 Windows 都一样），与系统目录保持一致。**这件事与代码签名无关**，那些免费证书也解决不了。已经装着的旧版本，跑一次升级安装即可生效
