- **A longer word that spells the whole input goes fourth** (upstream 1.6.1): `xian` puts 西安 fourth, `tian` 提案, `jie` 饥饿 — frequency used to bury them past 20th, and the context model can only recommend what it can see
- **The apostrophe separates syllables**: `xi'an` is read as xi + an and puts 西安 first (upstream 1.6.1)
- **Composition is more conservative**: the model composes only when the most likely reading is long enough, so a longer unlikely reading no longer replaces the first choice for inputs like `zhijieyong` (upstream 1.5.16)
- **New option, "Only lift exact pinyin matches to the top"** (Settings > General, off by default): the context model may only lift a candidate whose every syllable is typed in full; an input stopped inside the last syllable (`jinti`) is no longer turned into 今天. With fuzzy pinyin on, fuzzy readings count as exact
- **The voice key is left to the program while voice input is off** (upstream #29)
- **Settings are faster and steadier**: a window dragged across screens of another DPI rebuilds once when the drag ends (each screen used to cost over a second); switching the interface language no longer crashes; long English labels stay inside their cards; Restore default works when the chosen data folder cannot be reached
- **Installer**: a background service that is still exiting counts as running, so the upgrade waits for it instead of failing
