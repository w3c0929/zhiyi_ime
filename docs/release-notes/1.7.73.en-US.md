- **The recommendation model is now Zhiyi ML-Flash-1103** (upstream 1.6.4): ML-pumpkin-1026 cut to 8 layers with one head shared by word choice and composition; the languages and the input format are unchanged. Word-choice accuracy ties the previous version (Chinese words 88.2% → 88.8%, all-initials 77.7% → 79.1%, Chinese long input 76.0% → 76.3%; the differences are within sampling error)
- **Faster recommendations on the CPU**: the model reads the context once and keeps it (`laya.context_cache`, on by default; the last 4 contexts), and each key runs only the typed input and the candidates. A typical page (100 characters of context, 20 candidates) on a 4-thread CPU: about **13.5 ms → 3.4 ms**; on a graphics card about 4 ms → 2.5 ms. Off, or on a card, the whole graph runs as before
- **Larger model files**: the installer's `laya/` now holds both the whole graph and the one graph with the context cache (about 75 MB each); the first start rebuilds a local cache for this CPU (about 340 MB in `%LOCALAPPDATA%\zhiyu\laya-cache`)
