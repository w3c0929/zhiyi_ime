- **All model inference now runs on the local CPU; every graphics-card path is gone**: context recommendation, voice recognition and the offline translator all use the processor. Settings no longer offer "Run on / Recognition device"; there is nothing to time on a card any more
  - Context recommendation was CPU-first already; its card path is removed too, and a page still takes about 5 ms
  - All three voice models (SenseVoice / Fun-ASR-Nano / Qwen3-ASR) run on the CPU; Fun-ASR and Qwen keep running sherpa-onnx in their own process
  - The offline translator always starts with `--device none -ngl 0` (about 0.3 s a page) and keeps the shared-prefix optimization for the first page of a new context
- **A much smaller installer**: ONNX Runtime is the CPU package (14 MB instead of the 17 MB DirectML build plus an 18 MB `DirectML.dll`), and the recommendation model ships only as the slim one graph (53 MB); about 90 MB less than 1.7.76
- **The text recognized so far is shown while speaking**: the voice bar refreshes it about every half second (`voice.preview`, on by default); the final text still comes from the whole recording
- **Fixes the first key being lost in an Excel cell** (upstream #45): Excel's brief focus gap when it opens a cell no longer ends the composition, and the candidate window comes back when the focus returns; moving to another window still ends it
- The panels were trimmed accordingly: the Voice and Learning pages no longer have a device row
