- **全部改为在本机 CPU 上推理，去掉所有显卡加速**：上文推荐、语音识别、离线翻译现在都只用 CPU。设置里不再有「推理设备 / 识别设备 / 运行在」这些选项，也不必再为显卡测速
  - 上文推荐本来就是 CPU 优先，现在连显卡路径一起删掉，仍然毫秒级（一页约 5 ms）
  - 语音识别三种模型（SenseVoice / Fun-ASR-Nano / Qwen3-ASR）都在 CPU 上运行；Fun-ASR 和 Qwen 仍在独立进程里跑 sherpa-onnx
  - 离线翻译固定以 `--device none -ngl 0` 启动，CPU 上一页约 0.3 秒；仍保留「新上文首页一次算完」的共享前缀优化
- **安装包明显变小**：ONNX Runtime 换成 CPU 版（14 MB，替代 17 MB 的 DirectML 版 + 18 MB 的 `DirectML.dll`），推荐模型只带精简单图（53 MB），合计比 1.7.76 小约 90 MB

- **修复 Excel 里第一个按键丢失**（上游 #45）：Excel 打开单元格时焦点会短暂变成“无”，现在不再因此结束组字，焦点回来时候选窗重新出现；切到别的窗口仍照常结束
